# Выпускная квалификационная работа "Разработка веб-приложения для автоматизации заполнения унифицированных форм документов"

# Введение

На настоящий момент основной тенденцией является автоматизация ручного труда для уменьшения трудоёмкости различных процессов в разных сферах. Важно и то, что компьютерные программы помогают людям совершать меньше ошибок при выполнении рутинной работы. Эти особенности автоматизации решают проблемы документооборота, в частности, заполнения унифицированных форм документов в организациях и у индивидуальных предпринимателей.

Информация должна сохранять свои свойства, в особенности достоверность, полноту и понятность, при использовании документа в качестве её носителя. Эту проблему решает создание шаблонов для формализации и унификации документов. Однако многообразие и сложность получаемых шаблонов таких документов затрудняет их эффективное использование и контроль. Это приводит к возникновению ошибок, снижению качества сохраняемой информации и увеличению временных затрат на подготовку и проверку документов.

Таким образом, средства автоматизации нивелируют недостатки, возникающие при формализации и унификации документов, обуславливая исследования в данном направлении. Иными словами, актуальной становится разработка компьютерных программ, способных не только хранить и предоставлять инструменты для заполнения множества шаблонов документов, но и предотвращать их некорректное применение.

---

# Разработка программы

Процесс заполнения Личной карточки работника (Унифицированной формы N Т-2) будет использоваться в качестве объекта автоматизации при разработке веб-приложения. Выбор обоснован тем, что данная форма отличается значительным объёмом и разнообразием реквизитного состава, а также высокой ценой ошибок. Такой документ ведётся непрерывно, долго хранится и дополняется при изменении информации о сотруднике — это означает, что форма многократно применяется при кадровом учёте и не теряет актуальность с течением времени.

# Заключение

В ходе выполнения выпускной квалификационной работы была достигнута поставленная цель — разработано веб-приложение для автоматизации заполнения унифицированных форм документов, обеспечивающее снижение трудоёмкости процесса и предупреждение ошибок.

Решены все поставленные задачи:

1. Проведено исследование документирования в кадровом учёте. Выполнен сравнительный анализ существующих средств автоматизации заполнения унифицированных форм документов. Выявлены их достоинства и недостатки и обоснована необходимость разработки нового решения.
2. Обоснованы теоретические основы разработки нового решения, разработаны требования и спроектировано веб-приложение: функционал, алгоритмы, архитектура и структуры данных.
3. Обоснованы и выбраны программно-технические средства для реализации проекта.
4. Создан и протестирован на ключевом сценарии минимально жизнеспособный продукт.
   
Веб-приложение основано на микросервисной архитектуре с использованием актуального стека технологий, что является современным подходом при создании программных систем. Выполненная работа может служить основой для создания более комплексной и совершенной программной системы для заполнения унифицированных форм документов.

Перспективы развития проекта:

• использование возможностей искусственного интеллекта;  
• расширение функционала создания и улучшение заполнения форм;  
• поддержка электронной подписи и сертификатов;  
• предварительный просмотр документа с возможностью редактирования.
